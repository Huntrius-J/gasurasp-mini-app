# Мини-приложение "Расписание ГАГУ"

Это приложение предоставляет доступ к расписанию Горно-Алтайского государственного университета

## Основные возможности

- выбор нужного расписания по заданным фильтрам или строке поиска
- фильтровать можно по группам, преподавателям, аудиториям
- удобное представления расписания в виде списка за неделю
- выбор нужной даты или недели через календарь

## Запуск проекта локально

```sh
 npm run start -- --host
```

##  Деплой мини приложения

Для того чтобы захостить ваше приложение на сервера ВКонтакте нужно создать в vk-hosting-config.json и указать app_id вашего приложения.

```json
{
  "static_path": "build",
  "app_id": 0,
  "endpoints": {
    "mobile": "index.html",
    "mvk": "index.html",
    "web": "index.html"
  }
}
```

Далее можно запустить уже подготовленный скрипт:

```sh
npm run deploy
```

После чего, вы получите бессрочную ссылку на ваш мини апп.
